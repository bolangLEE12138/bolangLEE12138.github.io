Life页面改造：分区列表与自定义指南

Lee
25-Aug-2026 (Updated: 25-Aug-2026)
技术教程 › 优化
Hexo, 优化 
本次修改全程由AI执行，模型为Deepseek-V4-Flash。该技术文档由该模型生成。

一、涉及文件（只有 2 个）

文件 作用
source/life/index.md 页面标题、简介正文
themes/cactus/layout/life.ejs 页面布局、分区、列表、全部样式

二、工作机制（3 个关键点）

  1. layout 指定：index.md 的 front-matter 写 layout: life → Hexo 用 life.ejs 渲染此页
  2. categories 分类筛选：文章所在的目录决定它进哪个分区（_posts/探店/ → 🍽️ 分区；_posts/景点/ → 🏞️ 分区）——模板按分类自动筛选，无需手动维护列表
  3. sections 数组：分区配置表（title = 显示文字，category = 对应分类名），新增分区只改这里

三、日常自定义速查

想改什么 改哪里
页面标题（Footprint） index.md 的 title
副标题（斜体那句） life.ejs 的 .tagline 那一行
简介文字 index.md 正文
分区标题/图标 life.ejs 的 sections 数组里的 title
新增分区 sections 数组加一行 { title: '🎬 演出', category: '演出' } + 新建目录 _posts/演出/ 放文章
各级间距 life.ejs 的 CSS margin 值（1rem=16px）
列表/日期样式 life.ejs 的 CSS

四、写文章的约定

目录决定分区（hexo-auto-category 按目录自动生成分类）：

  • 放对目录即可，categories 不用手动写

五、踩过的坑（重要，别再踩）

  1. <div class="intro"> 包裹结构不能删——缺了简介渲染错乱、页面错位（已踩两次）
  2. ejs 注释用 <%# %>——裸写 // 会原样显示到页面
  3. <%- page.content %> 必须用 -%>——用 <%= %> 会转义 HTML，页面露出 <p> 标签
  4. 改完必须 hexo g（或 ./test.sh）才生效，改 CSS 同理
  5. 间距收紧的三层结构：header 的 margin-bottom（全局）+ .content 的 padding-top（全局）+ .life-hero 的 margin-top（页面级）——要贴导航栏需三层都改（life.ejs 里已有 .content 覆盖行）
