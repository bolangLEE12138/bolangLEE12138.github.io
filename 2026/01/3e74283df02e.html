魔改hexo-bilibili-bangumi插件（1）

Lee
21-Jan-2026 (Updated: 27-Jan-2026)
优化
教程

最近折腾 Hexo 博客，想把自己在 Bangumi (bgm.tv) 上的追番和阅读记录同步展示出来。使用了 hexo-bilibili-bangumi 插件，但原版的功能和样式无法完全满足我的需求。

主要实现了以下四个目标：

  1. 扩展数据源：从原本的“番剧/游戏/影视”改为“番剧/书籍/影视”，并修改对应的 API 获取路径。
  2. 重构导航UI：实现了三大板块的顶部 Tab 切换，并将所有内容（包括状态筛选按钮）居中展示。
  3. 交互优化：为过长的作品简介（Summary）添加了“展开/收起”功能。
  4. 自定义标签：利用 myComment 字段实现 Tag 展示（虽然牺牲了原本的评论功能）。

以下是具体的魔改记录。

1. 核心逻辑：打通“书籍”数据获取

原版插件默认只支持番剧、游戏和影视，且对应的 API 路径并不包含书籍。为了获取书籍数据，我深入 node_modules 修改了核心逻辑。

修改文件：

  • index.js (插件入口)
  • lib/get-bgm-data.js (爬虫与API逻辑)

主要改动：

  1. 在入口文件中注册了 book 命令，使其支持 hexo book -u。
  2. 配置 API 映射，将书籍的 type ID 设为 1（Bangumi API 定义）。
  3. 关键修复：修改了爬虫的正则表达式，使其能识别 /book/list/ 路径，防止因正则匹配失败导致的 username 获取错误。

2. 布局重构：居中导航与 Tab 切换

修改文件：lib/templates/bangumi.pug

实现效果：

  • 顶部新增高亮导航，自动判断当前页面类型（Type）并高亮对应入口。
  • 将“想看/在看/看过”的状态筛选按钮容器 (.bangumi-tabs) 设置为 Flex 布局，强制居中。

3. 体验优化：简介的展开与收起

修改文件：

  • lib/templates/bangumi.pug (注入全局 CSS/JS)
  • lib/templates/bgm-template.pug (应用到单个卡片)

实现逻辑：
利用 CSS 的 -webkit-line-clamp: 3 限制默认显示行数，配合简单的 JS 切换 expanded 类名。

4. 数据复用：用评论换 Tags

插件抓取的 JSON 数据中包含 myComment（我的评价）。为了让卡片显示更直观的标签（如“玄幻”、“技术”、“完结”），暂时决定牺牲评论文本，将其作为 Tag 的数据源。

修改文件：lib/templates/bgm-template.pug

实现逻辑：

  1. 在 Bangumi 收藏时，将标签写在评论框内，用空格分隔（例如：“科幻 史诗 必读”）。
  2. 修改模板，不再显示原始评论，而是通过 split(' ') 将其切割为数组。
  3. 循环渲染出胶囊样式的 Tags。

待优化：目前这样做意味着我无法在博客上展示长篇短评。

5. 插件修改保存

由于直接修改了 node_modules，一旦运行 npm install 修改就会丢失。为了解决这个问题，使用 patch-package 保存插件的修改内容。

  1. 运行 npx patch-package hexo-bilibili-bangumi 生成补丁文件。
  2. 在 package.json 中配置 "postinstall": "patch-package"。
  3. 将 patches/ 目录提交到 Git。
  4. 在新设备中运行npm install会自动执行patch的钩子，修改插件的内容。
